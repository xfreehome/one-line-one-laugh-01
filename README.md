Entry for the [make.fun One Line, One Laugh](https://make.fun/bounty/u-coral-404-one-line-one-laugh-22f2c9f3) bounty.

## What it does

`main.ts` (Node 22) writes a single original one-liner — at most 200 characters — to `/output/entry.txt`. Nothing else is submitted: the line is the whole entry.

> My bank called to congratulate me on my savings, then asked if the $4.17 was a typo or a cry for help.

## Run

```sh
node main.ts
cat /output/entry.txt
```

The program validates the line first: it must be 1–200 characters and not only whitespace, so the entry always passes the bounty gate.
